# Q31. Create a Web Blog using WordPress

The lab sheet asks for a WordPress practical demonstrating Anchor Tag, Title Tag, etc.
This is a website-building task in WordPress, not a standalone Python/Prolog program.

## Steps
1. Install WordPress locally using LocalWP, or use the WordPress installation provided by your college.
2. Sign in to the WordPress Dashboard.
3. Go to **Posts → Add New** and create a post titled `My AI Lab Blog`.
4. Add a heading, paragraphs, and an image using the block editor.
5. Add a link (anchor tag) by selecting text → Link and entering a URL.
6. Set the post title and permalink; publish or preview it.
7. Open the post and verify the title, headings, links, and image.

## HTML example for an anchor and title
```html
<!DOCTYPE html>
<html>
<head>
  <title>My AI Lab Blog</title>
</head>
<body>
  <h1>Welcome to My AI Lab Blog</h1>
  <p>This blog contains my Artificial Intelligence lab activities.</p>
  <a href="https://wordpress.org/" title="Visit WordPress">Visit WordPress</a>
</body>
</html>
```
